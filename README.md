📌 Overview

RAG AI System is a full-stack AI platform built using Retrieval-Augmented Generation (RAG) architecture.

It allows users to:

📄 Upload PDFs/documents
🧠 Extract and summarize content
💬 Chat with AI based on uploaded data
🎥 Collaborate using real-time video calls

The system combines LLM + Vector Database + Caching to deliver accurate, fast, and context-aware responses.

🔥 Core Features
📄 Document Upload (PDF, Docs)
🧠 AI-powered Summarization
💬 Chat with Your Documents (RAG आधारित)
🔍 Semantic Search inside documents
🎥 Real-time Video Calling (Discussion Mode)
🤖 AI Chat Assistant
⚡ Fast Response with Redis Caching
🔐 Authentication System (JWT आधारित)
📱 Fully Responsive UI
🧠 How It Works (RAG Flow)
User uploads a document (PDF/DOC)
Text is extracted and processed
Data is stored in vector database (ChromaDB)
User asks a question
Relevant chunks are retrieved
AI (Gemini) generates contextual answer
Cached response improves future performance
